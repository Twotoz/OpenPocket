# ADR-0001: ESP32-S3 as the main controller

- Status: accepted
- Date: 2026-07-31

## Decision

OpenPocket uses the ESP32-S3 as its main controller. RivetTX continues to
support the C3 for smaller standalone transmitters, but the C3 is not the
target platform for OpenPocket hardware.

## Rationale

- more GPIO for four to eight analog axes, switches, trims, and an encoder
- independent lines for CRSF, RX5808, and AT7456E
- dual-core separation between the control task and UI/services
- native USB for simulator/HID work and maintenance
- headroom for future display, storage, and diagnostic tooling

## Consequences

- firmware is built with `idf.py set-target esp32s3`
- the PCB must respect flash/PSRAM, USB, and strapping restrictions for the
  chosen ESP32-S3 module
- no GPIO map becomes final before the schematic and exact module variant are
  reviewed
